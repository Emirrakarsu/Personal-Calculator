CLI Basic Calculator
A simple, terminal-based arithmetic calculator handling core mathematical operations in a continuous input loop.

Features
Core Math Operations: Addition, subtraction, division, multiplication, and exponentiation.

Interactive Loop: Processes calculations continuously until explicitly terminated by the user.

Error Handling: Built-in try-except blocks to catch runtime type and value issues.

Supported Operations
add: Adds the first number to the second number.

sbs: Subtracts the second number from the first number.

dvd: Divides the first number by the second number.

mlt: Multiplies the two numbers.

exp: Raises the first number to the power of the second number.

q: Terminates the application session.

Usage
Launch the script via your terminal.

Enter the first and second numeric values when prompted.

Type the desired operation keyword (add, sbs, dvd, mlt, exp) or q to quit.

View the computed result directly in the terminal interface.

Requirements
Python 3.x (No external libraries required).
